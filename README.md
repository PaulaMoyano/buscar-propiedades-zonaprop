# buscar-propiedades-zonaprop

Skill para agentes: busca propiedades en venta en Zonaprop con el MCP de Playwright y cuenta los mejores resultados por precio/m².

Requiere el MCP de Playwright: `claude mcp add playwright -- npx @playwright/mcp@latest`

```
npx skills add PaulaMoyano/buscar-propiedades-zonaprop
```
